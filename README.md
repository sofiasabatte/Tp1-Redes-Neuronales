# Clasificador de Imágenes Médicas con Multi-Layer Perceptron (MLP)

Este proyecto consiste en el desarrollo, optimización y evaluación de un clasificador de imágenes médicas utilizando redes neuronales artificiales (MLP) en PyTorch. El objetivo principal es encontrar la configuración óptima de hiperparámetros y técnicas de aumentación de datos para maximizar la precisión del modelo en el diagnóstico visual.

El flujo de trabajo se dividió estrictamente en 5 fases:


##  Flujo del Proyecto

#### 1. EDA (Análisis Exploratorio de Datos)
Fase inicial orientada a **conocer el dataset** en profundidad antes de entrenar.

### 2. Prueba Manual Inicial 
Primer contacto con el modelado para **amigarme con la arquitectura y las herramientas**:

### 3. Búsqueda Automática de Hiperparámetros 
Automatización del proceso mediante *Random Search*, explorando el espacio de soluciones.

### 4. Refinamiento Manual de Candidatos Ganadores
Se **vuelve al entorno manual con las mejores opciones** 

### 5. Test (Evaluación Final)
Evaluación definitiva del modelo campeón para validar su rendimiento con datos nunca antes vistos.
